# Dib & Guitton

Site institucional responsivo do escritório Dib & Guitton, construído em PHP, HTML, CSS e JavaScript puro para hospedagem compartilhada.

## Requisitos

- Apache com suporte a `.htaccess`;
- PHP 8.0 ou superior;
- nenhuma dependência, banco de dados ou etapa de build.

## Executar localmente

Na pasta `dibeguitton`, execute:

```powershell
php -S localhost:8080
```

Depois acesse `http://localhost:8080`.

## Publicar no cPanel

Envie **o conteúdo desta pasta** para a raiz do domínio Dib & Guitton. O arquivo inicial é `index.php` e todas as imagens estão em `assets/images`.

Os botões de consulta jurídica abrem `https://calendly.com/fabio-dib/30min`. O botão de consultoria imobiliária da seção pós-locação abre `https://calendly.com/agendaguitton/meet`.
